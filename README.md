# GeekFactory 🎮🇯🇵

The ultimate premium boutique for anime collectors and gaming enthusiasts in Algeria.

## 🚀 Experience
GeekFactory is a high-end storefront featuring:
- **Floating Hero Banner**: Modern, centered visual direction.
- **Manga à prix découverte**: Curated collection of top-tier manga series.
- **Concept Store**: A dedicated location section with integrated Google Maps and store hours.
- **Premium Dark Aesthetics**: A sleek black and red design system with glassmorphism and motion.
